# 在线部署

在线版位于 `cloud-server/`，服务器身份由 Sites ChatGPT 登录验证。D1 绑定为 `DB`。构建采用 Vinext，SQL 迁移在 `drizzle/` 中。

公开源码中的 `.openai/hosting.json` 仅包含存储绑定。使用 Sites 部署时，先在自己的 Sites 账户创建站点，将平台返回的真实 `project_id` 写入本机配置。不得把部署写入令牌、私人数据、工作空间快照提交到公开仓库。Sites 插件工具会管理源码推送、构建档案、版本及部署。

部署必须应用数据库迁移。未经身份验证不能访问业务 API；站点入口可公开，业务数据由服务器工作空间成员权限控制。

若自行托管到 Cloudflare 或其他服务器，需要实现可验证的身份提供方与会话：替换 `app/chatgpt-auth.ts`，确认 `lib/crm-http.ts` 的身份来自服务器验证结果，而不是公开请求头。默认适配器仅在 Sites 的受信任身份代理下安全。不要将开发登录模拟用于公网。

## 验证

- 未登录 API 返回 401；页面只显示登录入口。
- 新账号看到空工作空间。
- 非成员不能读写其他工作空间。
- 只读成员写入返回 403；编辑者不能邀请或移除成员。
- 同一 revision 的并发保存只有一次成功，另一次返回 409。
- 邀请仅匹配邮箱可接受，过期或撤销链接不可使用。
- 第二个浏览器登录同一账号可以读取第一处保存的数据。
